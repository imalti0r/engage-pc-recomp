# Launcher artwork

These are original AI-generated illustration and lettering assets made for this
project from the user-approved launcher concept on 2026-11-03. Neither asset was
extracted from a game, a game screenshot, a game font or a commercial art download.
The title names the game this unofficial port supports; it is not an official logo.

- `cathedral.jpg`: empty Gothic cathedral, pale stone, blue stained glass, ivy,
  daylight and a dark navy area on the left. No characters, rings or lettering.
- `title.webp`: transparent white serif "FIRE EMBLEM / ENGAGE / PC RECOMP"
  lettering with red accents on the left and blue accents on the right.

Both were generated with the built-in image generation tool from the approved
concept, then converted to JPEG/WebP for distribution. The launcher renders its
controls and status separately. The source-release audit pins both assets by hash;
unreviewed replacement images remain blocked.

# Documentation screenshots

`launcher.png` and `setup.png` were supplied by the maintainer on 2026-11-04 for
the development launcher documentation. They show the launcher before a game is
selected and the empty setup form. Neither contains personal paths, key values,
gameplay, extracted icons or other extracted game assets.

The launcher background and lettering are the project's original generated
assets, with provenance in [the artwork notes](../../engage_setup/art/README.md).
The source-release audit allows these two screenshots by exact path and SHA-256;
changed images and additional unreviewed screenshots remain blocked.

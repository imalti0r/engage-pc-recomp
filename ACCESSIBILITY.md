# Accessibility

We welcome reports about barriers in Engage Setup, the runtime settings menu and
the project documentation. Accessibility support is still being evaluated.

The port has been tested on Windows 11 with an RTX 4060. Keyboard and gamepad input
work in gameplay, and F1 opens the settings menu. This does not establish that every
screen or action can be used with a keyboard alone.

Screen reader support, keyboard focus order, high contrast modes, text scaling and
color accessibility have not been systematically tested. We do not currently claim
compliance with an accessibility standard. Linux and Steam Deck are also unverified.
The port does not currently provide a documented set of additional in-game
accessibility features.

To report a barrier, [open an issue](https://github.com/veneito/engage-pc-recomp/issues/new/choose).
Include the version, affected screen, what you tried, what happened and what would
help. Mention your input device, display settings or assistive technology when
relevant. Screenshots are optional; remove private information before sharing.

Accessibility fixes and testing contributions are welcome. We cannot promise a
timeline, but clear reports help identify and prioritize improvements.
